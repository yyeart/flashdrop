# PostgreSQL владеет бизнес-корректностью

PostgreSQL является источником истины для Stock, Reservation, Order и долговечной идемпотентности. Условный UPDATE и row locks выполняются внутри транзакций; Redis используется только для rate limit и краткоживущего cache, поэтому его отказ не может создать overselling или повторную долговечную команду.
